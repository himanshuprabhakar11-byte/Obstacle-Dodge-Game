# 🎮 Obstacle Dodge Game

A fast-paced 3D obstacle avoidance game built in Unity. Test your reflexes by dodging obstacles, and surviving.


## 🕹️ Controls

| Action | Primary Key | Alternate Key |
| :--- | :--- | :--- 
| **Move Left** | `A` 
| **Move Right** | `D` 
| **Move Forward** | `W` 
| **Move Backward** | `S` 



## 🛠️ Built With

- **Engine:** [Unity](https://unity.com/) (Universal Render Pipeline - URP)
- **Language:** C#
- **IDE:** Visual Studio / VS Code

---
